What is an Agent ?

- Defination and what set AI Agent apart from standalone Large Language Models .
- An AI agent thinks and decides next steps dynamically .
- AI Agent (LLM based) = LLM + Tools + Loop
 - Features :
          - Goal Directed
          - Autonomous 
          - Interacts with  APIs , databases etc
          - Iterative , operates in a loop

- An AI Agent is not a new kind of model - it's an architecture pattern that warps an LLM in a reason-act-observe-loop .

The Agent Execution Loop :

  Perceive ----> Reason ----> Act ----> Observe 

  Loop continues untill the goal is reached .

  Termination Condition :
    - Agent decides it has the final answer .
    - Maximum iteration count reached .
    - Error or timeout triggers Fallback .

  What can go wrong  :
    - Infinite Loop (agent never decides it's done)
    - Hallucination tool calls (calling tools that don't exist)
    - Cost explosion (too many LLM API calls)
